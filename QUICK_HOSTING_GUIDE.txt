═══════════════════════════════════════════════════════════════

METHOD 1: NETLIFY (Easiest - Drag & Drop)
------------------------------------------
1. Go to https://www.netlify.com/
2. Sign up for free account
3. Drag the entire "website 2" folder onto Netlify
4. Done! Your site is live instantly

METHOD 2: GITHUB PAGES (Free Forever)
--------------------------------------
1. Create account at https://github.com
2. Create new repository (name it "techlife-website")
3. Upload all files from "website 2" folder
4. Go to Settings → Pages → Enable GitHub Pages
5. Your site will be at: yourusername.github.io/techlife-website

METHOD 3: VERCEL (Fast & Free)
-------------------------------
1. Go to https://vercel.com/
2. Sign up with GitHub/Google
3. Import your project (drag & drop folder)
4. Deploy - Done!
